    HUMBLE

    26 of 31 repos verified14 end-to-end

    Follows a repository's setup docs on a clean machine, repairs every step that breaks with evidence, replays the fixed guide from zero, and opens a PR with a README that provably works.       Pitwall

      0.62 s vs 1.11 sheld-out 2025 season

      Lap-time prediction, tyre-degradation modelling and a pit-stop decision engine on every F1 race from 2021 to 2025. Fitted on 2021-2023, tuned on 2024, tested once on 2025. Mean absolute error 0.62 s over 109,883 in-race predictions, against 1.11 s for repeating the last lap.

      Built with Python, dynamic programming and WebGL. live 3D app

        Local LLM serving and evaluation

        5 models, one 12 GB GPU35B MoE model: 83.7% and 75.6%

        Benchmarked five open models on MMLU and HumanEval and served them behind one llama.cpp router that loads each on demand. A 35B mixture-of-experts (MoE) model scored 83.7% on a 300-question MMLU subset and 75.6% on all 164 HumanEval problems.

          How I work

          Measure before building

          Break the errors down by cause first. Compare against a trivial baseline. Fix the biggest cause.

          One test pass

          Choose on a dev set, touch the held-out test once, and report every configuration that was run.

          Say what failed

          Rounds that did not beat the baseline go in the write-up with the reason.
